# Change the main application title to My Tasks

### Goal

Change the main application title from "Todo" to "My Tasks".

### Scope

Update the title displayed by the main application so it reads exactly "My Tasks".

### Constraints

- Make no other UI changes.
- Make no functionality changes.
- Preserve existing styling, layout, and behavior.

### Acceptance criteria

- AC-1: Given the application is displaying its main title as "Todo", When the application is opened after the change, Then the main title reads exactly "My Tasks".
- AC-2: Given the application before this change, When the title is updated, Then all UI and functionality outside the title remain unchanged.

### Non-goals

- Changing task behavior, styling, layout, or any other visible text.
